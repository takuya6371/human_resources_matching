# Andelaケーススタディ

[[vision]]で参照したAndela（アフリカ発のグローバル人材マーケットプレイス、評価額15億ドルのユニコーン）の成功モデルを深掘りし、AfriTalentへの示唆を整理する。

## ピボット年表

| 時期 | 出来事 |
|---|---|
| 2014年 | ナイジェリア・ラゴスで創業。Twitterで募集をかけ、700人の応募から最初の4人のジュニアエンジニアを採用。「厳選した若手を自社で訓練し、クライアントに派遣する」キャンパス型モデルでスタート |
| 2015〜2018年 | ケニア(2015)、ウガンダ(2017)、ルワンダ(2018)と物理キャンパスを展開。2016年にChan Zuckerberg Initiative主導のシリーズBで24M米ドル調達。2018年時点でエンジニア1,000人超 |
| 2019〜2020年（ピボット①） | ジュニア訓練モデルから中堅・シニアエンジニア重視へ転換。市場が求めていたのは「育てた人材」より「即戦力」だったため。ジュニアエンジニア約400人のレイオフを伴う痛みを伴う転換 |
| 2020年（ピボット②、最大の転換） | 物理キャンパスを閉鎖し、完全リモートモデルへ。訓練施設のある国に限らず、アフリカ40カ国以上から人材を調達可能に。コロナ禍のリモートワーク普及と重なり、「訓練集約型ビジネス」から「スケーラブルな分散型人材マーケットプレイス」へ変貌 |
| 2020年以降 | アフリカに限らずラテンアメリカなど他地域の人材にも対象を拡大し、"match-as-a-service"型のグローバル人材マーケットプレイスへ |
| 2021年9月 | SoftBank Vision Fund 2主導のシリーズEで200M米ドル調達、評価額15億ドルでユニコーン化（アフリカ発の人材マーケットプレイスとして初） |
| 2023年 | ミュンヘン拠点のIT人材ネットワーク「Casana」を買収し、欧州の存在感を強化 |
| 2024年 | 審査済みエンジニアのネットワークが15万人超、エンタープライズ顧客からの売上が前年比40%増、売上264M米ドル、従業員約1,300人 |

累計調達額は381M米ドル（8ラウンド）。

## クライアントの内訳（デマンドサイド）

- **地域別売上比率**: 米国が売上の約75%を占め、次いで英国・ドイツ
- **主要クライアント**: Goldman Sachs、GitHub、ViacomCBS、Mastercard Foundry、Cloudflare、Casper、InVisionなど。特にGoldman Sachs・GitHub・ViacomCBSなどのエンタープライズ顧客だけで売上の60%以上を占める
- 人材供給側は当初ナイジェリア・ケニア・エジプトが中心だったが、2023〜2025年にかけてラテンアメリカからの供給が約150%増加。これは米国とのタイムゾーンの近さ（ニアショアリング）を活かすため

## 契約形態

### 人材側の契約形態
- **創業〜2020年**: エンジニアはAndelaの**フルタイム正社員**として雇用され、クライアント企業に「派遣」される形（給与を払い、差額を得るマークアップモデル）
- **2020年9月（転換点）**: 正社員雇用を廃止し、**「ギグワーカー/業務委託契約」に一斉移行**。コスト削減が主目的とされ、当時は「福利厚生や雇用の安定性を失う」として現地メディアで物議を醸した
- **現在**: Andelaの人材（"Talent"）はAndela自身の従業員、独立契約者、下請け、エージェントなど**複数の契約形態が混在**する柔軟な構成

### クライアント側の契約形態
- クライアントはAndelaと**Master Services Agreement（MSA）** を締結し、個々のエンジニアと直接契約するのではなく、**Andela経由で人材を"staffing"してもらう**形
- ほとんどの契約はシニア〜ミドルシニア人材を対象とした**月額リテイナー（月極め契約）**
- **最低契約期間は12ヶ月**
- **料金水準: 月額6,000〜14,000米ドル/人**（経験・市場によって変動）— 円換算でおよそ月90万〜210万円
- **重要な仕組み: 契約期間中にクライアントが契約者を直接雇用に切り替える場合、5万米ドルの買取（バイアウト）手数料が発生**。これはクライアントが人材を"中抜き"してAndelaを排除するのを防ぐ仕組み

### AfriTalentへの示唆（契約形態関連）

**① 料金水準の想定が甘かった可能性**
[[monetization-simulation]]の業務委託シナリオでは月40万円という控えめな数字を使ったが、Andelaの実績（月90万〜210万円）は数倍高い水準。Andelaはシニア人材・エンタープライズ顧客中心なので単純比較はできないが、人材の経験値が上がれば想定より高い単価が狙える余地がある。

**② バイアウト条項は真似すべき仕組み**
「契約者を直接雇用に切り替えたければ手数料を払う」という条項は、AfriTalentの継続収益（マークアップ）を守る上で理にかなっている。業務委託モデルを採用する場合、契約書にこの仕組みを組み込むべき。

**③ 人材側の契約形態の変更は評判リスクを伴う**
Andelaが正社員から業務委託へ切り替えた際、現地では「待遇の切り下げ」として批判された。将来コスト削減のために人材側の契約形態を変える場合、この前例は評判リスクとして意識しておく必要がある。

## AfriTalentへの示唆

**① 「狭く始めて後で広げる」戦略は実際に機能した、ただし時間軸は長い**
[[positioning-africa-vs-global]]で決めた「まずアフリカ特化→後で拡張」という方針は、Andelaがまさにそれを地で行った実例。ただし、アフリカ限定から他地域拡張までに約6〜7年かかっている。焦って広げる必要はない。

**② 「手厚い訓練・伴走モデル」は結局スケールしなかった、という重要な警告**
最初のキャンパス型（訓練・住居・伴走込み）は資本集約的すぎて、Andela自身がこれを捨てて「既にシニアな人材を審査してマッチングするだけ」の軽量モデルに転換した。これは今AfriTalentが設計している手厚い支援機能（ビザ対応、面接コーチング、定着フォロー、[[phase0-non-monetary-exchange]]や[[monetization-simulation]]の運用コスト）が、スケールする段階でボトルネックになりうるという先行事例としての警告。Phase 0〜2では差別化として有効でも、将来的には「軽量化」への転換を意識しておく必要がある。

**③ リモート化ピボットは、AfriTalentが直近で設計した業務委託シナリオそのもの**
Andelaの最大の転換点（2020年のフルリモート化）は、[[scope-japan-resident-vs-overseas]]で議論した「業務委託ならビザ・所在地の制約が消える」という発想と同じ。Andelaの成功が、この方向性の実証済み前例と言える。

**④ ジュニアからシニアへのシフトも参考になる**
「育成した若手」より「即戦力人材」の需要が強かったというAndelaの学びは、AfriTalentが現在ターゲットにしている「日本の大学で学ぶ留学生（＝まだジュニア）」の位置づけを将来的に見直す可能性を示唆する。企業側の需要を見ながら、経験者採用にも対応できる柔軟性を持たせておくのが良い。

**⑤ ユニコーン級の成功には相応の資金調達が伴う**
Andelaは累計381M米ドルを調達している。[[vision]]で描いた長期ビジョンの規模感（人材インフラ化）を本気で目指すなら、いずれ2人体制のブートストラップから脱却し、本格的な資金調達フェーズに入る前提を持っておく必要がある。

**⑥ Andelaの成功は「市場開拓」ではなく「コスト最適化＋タイムゾーン適合」が主因だった**
[[motivation-for-companies]]で整理した企業の採用動機のうち、Andelaが実際に刺さっていたのは①人手不足解消・コスト最適化であり、②市場開拓（アフリカ市場への布石）はAndelaの主要な牽引力ではなかった。米国企業がアフリカ人材を使う理由は「アフリカ市場に興味があるから」ではなく、単純に「安くて質が高く、時差も比較的近いから」だった。

**⑦ 日本とアフリカのタイムゾーンの壁はAndelaの前例より深刻**
米国とラテンアメリカ/西アフリカの時差は数時間程度だが、**日本とアフリカの時差は6〜9時間**あり、Andelaが享受したニアショアリングの利点をAfriTalentはそのまま享受できない。業務委託・リモート契約モデルを進める場合、リアルタイムでの共同作業のしづらさが米国企業向けモデルより大きな障壁になる可能性がある。非同期作業に向いた業務（バッチ処理、ドキュメンテーション、QA等）から始めるなど、時差を前提にした業務設計の工夫が必要。

## 未決定事項
