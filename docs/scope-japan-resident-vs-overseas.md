# 対象範囲：日本在住者限定 vs 海外からの直接採用

当初の対象は「日本在住の外国人（アフリカ人留学生等）」だが、この前提は恒久的な制約ではなく、条件次第で変わりうる。[[positioning-africa-vs-global]]と同じ構造の、もう一つの絞り込み軸（対象者の所在地）として整理する。

## 現在の前提（日本在住者限定）が持つメリット

- **ビザ手続きが軽い** — 「在留資格変更」（留学→就労）で完結し、比較的短期間（1〜3ヶ月程度）
- **審査・面接がしやすい** — 対面イベントや現地コミュニティ経由での信頼構築がしやすい
- **企業側のリスクが低い** — 「日本にいる人」「日本語学習の実績が可視化されている人」なので、採用企業の心理的ハードルが下がる
- 運用の専門性を絞ることで勝てる場所を作るビーチヘッド戦略の一部（[[positioning-africa-vs-global]]と同じロジック）

## 前提が変わる条件

1. **在日人材プールの枯渇** — 日本在住のアフリカ人留学生は絶対数が少ない（全国でも数千人規模と見られる）。[[monetization-simulation]]のPhase 3で想定した「月10件成約」を狙うと、在日人材だけでは早晩供給が追いつかなくなる可能性が高い。これは"選択"ではなく"必然"としてこの前提を変えざるを得なくなるシナリオ
2. **企業側からの明示的な要望** — 「日本にいる人に限らず、アフリカから直接採用したい」という需要が増えてきたら拡大のシグナル
3. **実績とオペレーションの成熟** — Phase 2で在日人材の成功事例が積み上がり、ビザ・定着支援のオペレーションが型化されてから、より複雑な海外直接採用に手を広げる方が安全

## 業務委託（リモート契約）ならビザ問題自体を回避できる

正規雇用・在留資格前提の話とは別に、**業務委託（リモート契約）モデル**（[[monetization-simulation]]の業務委託シナリオ参照）を使えば、人材は日本に来る必要がなくアフリカに居住したまま働ける。この場合、以下の前提が根本から変わる:

- COE（在留資格認定証明書交付申請）や在留資格変更が不要になる
- 在日人材プールの枯渇という制約自体が発生しない（対象人材プールが最初からアフリカ全域に広がる）
- 一方で、対面が必須の職種には使えず、リモート向きの職種（ITエンジニア等）に限定される
- 偽装請負・越境決済・為替リスクという別種の実務課題が発生する

つまり「日本在住者限定 → 海外直接採用へ拡大」という段階的な話とは別に、**業務委託モデルを選べば最初から所在地の制約を外せる**という選択肢がある。正規雇用（在留資格が必要）と業務委託（不要）を両輪で持ち、職種や企業の希望に応じて使い分けるのが現実的かもしれない。

## 前提を変えた場合の影響（正規雇用の場合）

| 項目 | 在日人材（現在） | 海外から直接採用（拡大後） |
|---|---|---|
| ビザ手続き | 在留資格変更（比較的短期） | 在留資格認定証明書交付申請（COE）、+ 現地大使館でのビザ取得。期間は3〜6ヶ月以上に伸びる |
| 審査・面接 | 対面イベント活用可 | オンライン完結、タイムゾーン調整、信頼構築のハードルが上がる |
| 企業側の心理的ハードル | 低い（会える、日本語実績が見える） | 高い（会ったことがない人を採用する不安が増す） |
| 追加コスト | ほぼなし | 渡航費・住居手配などの引っ越し支援（新たなコストセンター、あるいは新たな課金対象） |
| TAM（対象人材数） | 数千人規模（狭い） | アフリカの英語/仏語圏労働市場全体（桁違いに大きい） |

## 位置づけの提案

まず日本在住者で勝ちパターンを作り、Phase 2〜3で海外直接採用に拡張する形で、既存のフェーズモデル（[[monetization-simulation]]）に組み込むのが筋が良い。ただし人材プールの枯渇は成長のボトルネックとして早めに顕在化しうるため、**Phase 2の段階で在日人材の供給数を一度実測しておく**ことが望ましい。

## 未決定事項

- 海外直接採用に拡張する際の引っ越し支援を、コストセンターにするか新規課金対象にするか
- COEプロセスに対応するための提携先（現地大使館・送り出し機関）の選定
