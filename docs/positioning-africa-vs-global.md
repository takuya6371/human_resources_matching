# アフリカ特化 vs 海外人材への抽象化

残作業.txtの最初の論点「アフリカ人材に特化するサイトで良いのか、海外人材と１つ抽象化もできるのではないか」に対する検討。

海外人材を雇う動機を「国籍に依存する部分」と「依存しない部分」に分解すると、この論点に答えが出る。

## 国籍に依存しない動機（普遍的）

- 人手不足の解消
- コスト最適化
- ESG/ダイバーシティ対応

これらは別にアフリカでなくてもベトナムでもインドでもフィリピンでも成立する。企業側の本音ベースでは、この3つが採用理由の大半を占めるケースが多く、国籍への強いこだわりは薄いのが実態。

## 国籍に依存する動機（アフリカ特有）

- アフリカ市場開拓の布石（商社・自動車メーカー等）
- 英語圏アフリカの語学力
- 送り出し国としての「空き具合」（ベトナム・フィリピン・インドは既に飽和、アフリカはブルーオーシャン）
- TICAD等の政策的追い風

「なぜアフリカなのか」を積極的に選ぶ理由にはなるが、②市場開拓を除くと副次的な理由が多い。

## 本質的な決め手は動機よりも運用上の理由

「サービスをアフリカに特化すべきか」を決めるのは、企業側の動機よりも**供給側（人材獲得・審査・ビザ対応）のオペレーションが国ごとに全く別物**という事実。

- ビザ手続き、送り出し機関、大学の留学生課との関係、コミュニティでの信頼構築は国・地域ごとに個別に積み上げる必要がある
- ベトナム・フィリピン・インド向けチャネルは既に競合（大手人材会社）がひしめいており、後発で入るのは厳しい
- アフリカはこの運用インフラがまだ手薄で、"誰もちゃんとやっていない"という参入余地がある

企業の採用動機だけを見ると「別に海外人材全般でいい」という結論に寄りやすいが、事業として勝てるかどうかは「オペレーションの専門性をどこに集中投資するか」で決まる。

## 結論（暫定）

最初から「海外人材」に抽象化すると、
1. 競合の多い既存チャネル（ベトナム/フィリピン/インド）と真正面から戦うことになり差別化が消える
2. オペレーションの専門性が分散し、どの国に対しても中途半端になるリスクがある

→ **立ち上げはアフリカに特化してブランド・審査ノウハウ・現地パートナーシップという"勝てる場所"を作り、モデルが確立してから他地域に横展開するビーチヘッド戦略**が筋が良い。

Andelaも当初はアフリカ限定で始め、後から対象地域を広げた前例がある（[[monetization-options]]の7番参照）。
