# Phase 0：無償提供の代わりに何をもらうか

[[monetization-options]]で整理した段階的マネタイズ戦略のPhase 0（実績ゼロ〜10件成約まで）において、金銭の代わりに何を対価として受け取るかを設計する。

## 背景

Phase 0で無理に高単価モデルを成立させようとすることが、マネタイズ不安の主因だった（実績のない段階でPhase 2相当の成功報酬モデルを売ろうとしていた）。Phase 0は意図的に「稼がない」代わりに、Phase 1以降の営業・プロダクト改善に使える資産を集める段階と位置づける。

## 対価の一覧（カテゴリ別、依頼しやすさ順）

### ① 証拠・実績資産（最重要、依頼もしやすい）
- 導入事例としての掲載許可（企業名・ロゴ・採用背景の公開）
- 採用された学生・企業担当者へのインタビュー動画/写真撮影の許可 — 「興味喚起」施策で議論したAI生成ショート動画の元ネタになる
- 定量成果の開示許可（採用スピード、業務改善効果など数値で語れるもの）

### ② フィードバック・共創（低コストで頼みやすい）
- 定期ヒアリング・アンケートへの協力（入社30日・90日・180日フォローアップ）
- UI/UXやマッチング精度への率直なフィードバック
- ベータ機能の先行テスト協力

### ③ 紹介・拡散（企業側の熱量次第で価値が跳ねる）
- 人事担当者コミュニティ・業界団体内での口コミ紹介
- 共同執筆記事・登壇協力（「弊社のアフリカ人材採用事例」として）

### ④ 将来収益の予約（依頼のハードルはやや高いが営業効率化に効く）
- Phase 1以降の有償化時に優先契約するLOI（意向確認書）
- 次回採用時は有償プランにコミットしてもらう覚書

### ⑤ ネットワーク資本（機会があれば）
- 大学の留学生課・自治体の外国人材誘致施策との接続
- 他部署・他社人事への紹介

## 依頼タイミング設計

| タイミング | 依頼すること | 目的 |
|---|---|---|
| 契約時（無償提供の合意） | 事例化許可、フィードバック協力への同意 | 最初に握っておくことで後から言い出しにくい状況を回避 |
| 内定〜入社時 | インタビュー撮影、定量データの共有 | 一番"熱量が高い"タイミングで証拠を集める |
| 入社30日後 | 満足度アンケート、初期フィードバック | 製品改善データの収集 |
| 入社90〜180日後 | 定着状況の開示、口コミ紹介の依頼 | 定着実績という一番強い証拠が揃うタイミング |
| Phase 0終了時（実績が語れる段階） | LOI（次回以降の有償契約意向） | Phase 1への移行をスムーズにする布石 |

## Phase 0の対象企業数の上限

**上限: 8社、かつ「8社 or 6ヶ月」のいずれか早い方で締め切る**

- **運営キャパシティ** — 手厚い伴走（審査・ビザ対応・面接コーチング・定着フォロー）を少人数体制で質を落とさず見られるのは現実的に5〜8社程度
- **歩留まりを見込んだ逆算** — 内定・入社・定着までの完走率を6〜7割と見積もると、8社受け入れれば5社前後の成功事例が残る
- **事例の多様性の確保** — 5社あれば、ITスタートアップ／中堅企業／旗艦的な大企業など異なるセグメントの事例を揃えられ、業種別の訴求（[[motivation-for-companies]]の①②③）それぞれに説得材料ができる
- **無償期間の恒久化を防ぐ** — 件数の上限だけだと営業が停滞した際にずるずる伸びる抜け道になるため、期間の上限も併用する

トレードオフ: 5社に絞ればさらに運営は楽になるが事例の多様性が減る。15社に増やせば多様性は増すが、支援の質低下・定着率低下のリスクが上がり、Phase 0の価値提案（伴走の質）と矛盾する。
