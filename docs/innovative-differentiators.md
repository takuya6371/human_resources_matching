# 革新的な売り（サービスの差別化ポイント）

単なる機能追加ではなく、企業側のリスク認識そのものを変える差別化ポイントを検討する。[[competitive-differentiation-linkedin]]で議論したLinkedInとの差別化をさらに一歩進め、営業の難しさ（[[approach-to-japanese-companies]]参照）自体を解決する武器として位置づける。

## 1. 成果保証（交代・返金保証）

「採用した人材が3ヶ月以内に離職したら、無料で再マッチング（または返金）」を正面から打ち出す。人材紹介業界では珍しくないが、実績ゼロの新規サービスがこれを最初から掲げると、**リスクを運営側が引き受ける姿勢**として強いメッセージになる。無名サービスへの警戒感を直接崩す一手。

## 2. AI同時通訳付き「言語の壁ゼロ面接」

面接をリアルタイムAI通訳付きで実施し、日本語面接への不安を面接の場でその場で消す。営業の場で実際にデモできるのが強み — 「うちのサービスはこういうものです」と説明するより、「じゃあ今この場で体験してみてください」と言える機能は営業効率に直結する。AI機能の中でも最も"見せられる"形の差別化。

## 3. 「アフリカ市場開拓」とセットの人材紹介パッケージ化

単なる人材紹介ではなく、**「採用した人材＋アフリカ市場参入の簡易コンサルティング」をセット商品にする**。予算の出どころがHR部門だけでなく経営企画・海外事業部にも広がり、「コスト」ではなく「戦略投資」として意思決定してもらえる。競合の人材会社には真似しにくい（アフリカ特化ならではの強み）。商社・大企業への突破口として特に有効。

## 4. 独自の人材認定バッジ制度

Toptalの「上位3%」のように、AfriTalent独自の審査基準に基づく認定バッジを作り、「このバッジがある人材は品質保証済み」というブランドを確立する。PRのフックにもなり（「日本初のアフリカ人材品質認定制度」等）、長期的なブランド資産になる。

## 推奨の組み合わせ

**①成果保証＋②AI同時通訳面接** の組み合わせが一番強い。理由は、この2つが企業側の最大の不安（採用ミスマッチ・言語の壁）に直接刺さり、かつ**営業の場でその場で体験・証明できる**ため、日本企業への営業の難しさ自体を解決する武器になるため。③のパッケージ化は商社・大企業向けの中長期の一手として並行して育てる。
