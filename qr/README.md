# QRコード

イベント配布用。`qr/generate.py` で再生成できる。

| ファイル | 遷移先 | 用途 |
|---|---|---|
| `start.*` | `/start` | 人材・企業の2択を出す。配布物を分けないとき |
| `talent.*` | `/login?mode=signup&role=talent` | 人材の登録フォームへ直行（1画面省ける） |
| `company.*` | `/login?mode=signup&role=company` | 企業の登録フォームへ直行 |

- **SVG が印刷入稿用**。拡大しても劣化しない。PNG は確認用。
- 誤り訂正は **H（最高・約30%復元）**。印刷物が汚れても、中央にロゴを置いても読める。
- 色は本文と同じ `#1C1B18` / `#FAF8F4`。真っ黒・真っ白にしたい場合は generate.py の dark/light を変更。

## 独自ドメインに切り替えるとき

`generate.py` の `BASE` を書き換えて再実行するだけ。
なお netlify.app のURLはドメイン追加後も生き続けるので、
**印刷済みのQRが無効になることはない**（1ホップ増えるだけ）。

## 印刷時の注意

- 最小サイズは **2cm角** を目安に。それ以下だとスマホのカメラが迷う
- QRの周囲の余白（クワイエットゾーン）を潰さないこと。SVG に含めてある
- 背景に柄や写真を敷かない
