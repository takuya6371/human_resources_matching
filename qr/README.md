# QRコード

イベント配布用。`qr/generate.py` で再生成できる。

| ファイル | 遷移先 | 用途 |
|---|---|---|
| `start.*` | `/start` | 人材・企業の2択（日本語） |
| `start-en.*` | `/start?lang=en` | 同上（英語で着地） |
| `talent.*` | `/login?mode=signup&role=talent` | 人材の登録へ直行（日本語） |
| `talent-en.*` | `…&lang=en` | 同上（英語） |
| `company.*` | `/login?mode=signup&role=company` | 企業の登録へ直行（日本語） |
| `company-en.*` | `…&lang=en` | 同上（英語） |

- **SVG が印刷入稿用**。拡大しても劣化しない。PNG は確認用。
- 誤り訂正は **Q（25%復元）**。H（30%）だと company-en が 45x45 まで密になり、
  既定サイズでデコードできなかった。中央にロゴを置くなら H に戻し、
  必ず実機のカメラで読めるか確かめること。
- 色は本文と同じ `#1C1B18` / `#FAF8F4`。

## 言語について

`?lang=en` が付いたQRは、端末が日本語設定でも英語で着地する。
会場では日本語版と英語版を並べて置くのが取りこぼしが少ない。
一度読むと localStorage に保存され、以後その言語が維持される。

## 印刷時の注意

- 最小サイズは **2cm角** を目安に。それ以下だとスマホのカメラが迷う
- QRの周囲の余白（クワイエットゾーン）を潰さないこと。SVG に含めてある
- 背景に柄や写真を敷かない
